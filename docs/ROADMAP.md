# AIGATE 目标、里程碑与执行路线图

裁决日期：2026-09-07（Asia/Hong_Kong）。方向已确认；本轮仅完成文档。战略依据：[PRODUCT_STRATEGY](PRODUCT_STRATEGY.md)；当前事实：[CURRENT_STATUS](CURRENT_STATUS.md)。

## 1. 当前起点与成功标准

产品已有公开比较入口、帮助、工具、赞助/提交入口、本机 raw-first 数据流程和生产部署。9 月 3 日任务记录显示 Node 测试 106/106、Crawlee 测试 42 项、构建和浏览器发布验证通过；这是历史证据，本次未复跑产品或在线状态。记录入口：[发布 QA](../taskexec/cardnav-web/docs/qa/p0_codex_t09030447.p003.md)、[数据 QA](../taskexec/cardnav-web/docs/qa/p0_codex_t09030447.p002.md)。

项目当前处于“已建站与受控数据运营，进入经营闭环验证”。不能因已有赞助按钮就标记商业闭环完成，也不能把文档完成等同于 M0 指标基线、M1 排名治理或后续里程碑完成。

长期目标：持续帮助用户作可信比较，获得高质量导流，通过固定赞助、付费排名、广告及我方站点导流支持再投入；SEO/GEO 领先由实际查询表现、引用及用户行动证明。北极星为每周完成可信比较后产生有效站外导流的用户数；基线建立前不设排名承诺或收入日期。

## 3. 可验收里程碑

各阶段采用“先定义小范围和验证窗口 -> 验收 -> 决定扩张”。经营数值待 M0 基线后由负责人记录具体目标，不把旧三档表的数字当运行配置。经营指标负责人为 wind；技术执行者在对应 tasklist 认领，文档不代替任务分派。

| ID / 状态 | 依赖与交付 | 退出证据 | 停止或缩小范围条件 |
|---|---|---|---|
| M0 待实施：事实与指标基线 | 盘点核心页面族和现有埋点；定义事件、去重、隐私与完整观测窗口 | 每个核心页面族有用户任务、owner、索引策略和主要动作；用浏览器验证曝光/比较/外跳链与重复排除；产出基线报告，缺失写 unavailable | 重复或敏感事件无法清理时，降为聚合统计；流量不足就延长观察，不伪造趋势 |
| M1 待实施：信任与排名合同 | 依赖 M0 事件口径；审查现有 sponsor 置顶、参考 rank、初值 50；实现独立赞助区和自然榜，明确关联站披露；验证综合评分方法 | 修改付款/赞助/自营标识时，自然候选、分值及顺序不变；用户可见来源、采样时间、方法版本和纠错入口；可重复计算、缺失/异常/并列测试通过，真实入口验收 | 维度不可比或缺数据则显示分项和未知，延后总分发布；披露失败的商业位不上线 |
| M2 待实施：需求机会队列 | 依赖 M0/M1 基础；用搜索无结果、问题、来源变化形成候选 | 每项记录需求证据、独有价值、目标用户、来源、维护成本、负责人及接受/更新/合并/拒绝决定；真实用户问题验证队列优先级 | 多数候选没有价值或无维护预算时停止扩页，修现有入口 |
| M3 待实施：可信决策闭环 | 依赖 M1/M2；先一个任务场景的比较/成本工具与轻量选择器；完整代理作为后续扩展 | 用户从正常入口完成输入、同单位比较、来源核对和外跳；显示不适合原因、未知和官方备选；推荐可复现；在预定观察窗口内改善完成率或有效导流且不损害信任 | 数据不够或推荐不可解释时退回中性比较，仍可观察需求；不扩大代理功能 |
| M4 待实施：SEO/GEO 价值验证 | 依赖 M2/M3；主题页、数据页、工具页共同支持任务，记录基准查询/问题集 | 页面通过独有价值、可读正文、来源日期、canonical、内部链接、索引/过期和结构化数据检查；固定查询/引擎记录表现与实际引用；观测不只依赖热点/品牌词，且带来有效动作 | 索引增加但决策下降、内容重复或维护欠账增加时冻结新页面族，合并或退役 |
| M5a 待实施：固定商业交付 | 依赖 M0/M1 和 M3 可用闭环；M4 不必先达到“前三”；试点固定赞助、付费排名和广告 | 有商家接受的版位/周期/费用/披露/报告/中断处理约定；真实曝光与点击可核对；自然榜隔离测试和入口验收通过；复盘实际交付、贡献毛利、信任变化与续约意愿 | 无有效受众或商家不愿续约则缩减库存/调整价值，暂缓后台；不以买自然名次弥补效果 |
| M5b 待输入：我方站点接入 | 依赖 M5a；登记用户指定站点和关系、公开字段、目标页、归因权限；数据仍走既有生命周期 | 正常比较入口可见自营/关联披露并到正确目标；点击与目标站授权反馈能核对；自然排名对关系标识不敏感；关联收入与外部收入分账 | 未知域名、关系或数据授权时仅保留规划；缺转化反馈只报点击，不推算成交 |
| M6 待实施：商家数据与增长 | 依赖 M5a，结合 M5b 反馈；先人工报告验证价值，再接授权 Feed/后台 | 资料的自报/验证/过期/拒绝状态可追溯；更新不绕过 raw→merge；报告解释曝光、有效导流、覆盖缺口和数据健康；商家持续使用并愿续费后扩建后台 | 审核/支持成本超过价值时保留轻量提交与报告；无统计样本不生成伪“趋势” |
| M7 后置：数据与接口产品 | 依赖 M6 稳定数据和外部需求；评估历史、提醒、摘要、API/报告 | 独立设计伙伴证明反复需求/付费意愿；许可、版本、配额、来源日期、缓存与成本可交代；接口只读 runtime/snapshot；验收实际使用 | 无需求、权利不清或可靠性成本过高时保留站内工具，不建商业 API |
| M8 持续：质量与自治上限 | 从 M1 起实施基础，扩展依赖各阶段验证 | 每个页面族有刷新/纠错 owner 和预算；自动化 dry-run、审计、幂等、并发上限、停止入口与回滚；稳定期错误/返工和恢复指标达约定门槛才扩自动化 | 来源变化、错误预算耗尽或信任下降时回退候选/人工审核；高影响评分及商业规则变更仍需审查 |

阶段验收资料必须记录样本、时间、环境、结果和未覆盖项。运行功能需自动化与真实入口验证；部署再核对 AIGATE 及 LikeShop 路由。完成只由 tasklist 的实现、QA、真实提交与复读结果确认。

## 4. 北极星与指标字典

主指标：香港时区自然周内，在定义的比较/决策动作后触发有效外跳的去重用户数。无可靠跨设备身份时采用匿名访客口径并明确局限，不能称为精确人数。定义由 M0 固化；不收集账号、API 密钥或不必要的搜索隐私文本。

| 指标 | 定义与来源 | 排除、口径与边界 |
|---|---|---|
| 有效导流用户 | 第一方事件串联比较动作与随后明确目标的外跳，按周去重；M0 为现有事件补必要字段 | 去除测试、已识别机器人、重复连点；没有可串联证据不冒充“比较后”；跨设备不强行合并 |
| 比较完成率 | 完成定义比较动作的会话 / 有资格进入该比较流程的会话 | 定义起止和窗口；不靠页面浏览假定完成 |
| 决策帮助护栏 | 用户满意/完成任务、不购买/选官方的原因与信任反馈 | 不强制外跳；“不买”可有价值但不计导流 |
| 获取与可见度 | Search Console 汇总的查询/页面点击，合规来源的排名样本；GEO 固定问题实际引用 | SEO/GEO 分开；记录样本分母、引擎、地区、日期；不可归因数据单列 |
| 赞助交付 | 实际可见商业位曝光、有效点击、周期与版位，按合作报告 | 定价先按固定交付；CTR 分母是相同库存曝光；点击不代表转化 |
| 自营站效果 | 关系明确目标的导流及获授权回传的合格动作 | 单独标记自营；无回传时转化为 unavailable，不写零也不虚估 |
| 商业结果 | 外部实收/应收口径、续约、收入集中度与贡献毛利 | 分清预收与周期收入；内部推广价值不重复计入外部收入；不把流水当利润 |
| 新鲜与质量 | 页面族有效证据覆盖、纠错率、错误恢复耗时 | 记录各来源窗口与审核状态；新鲜不保证准确 |
| 扩展效率 | 单个有效页面族的维护成本、候选采纳率、人工复核/返工 | 生成页数不是目标；成本纳入数据、编辑和运营 |

实施时每项补齐事件名、必需字段、窗口、去重、owner、数据源、访问权限和可重复验收用例。现有 Umami/点击端点只是可复用起点，当前没有证明完整归因或商业报表已建立。

## 6. 后续 tasklist 建议与批准范围

本次文档 tasklist 已获授权连续执行。以下是已选路线的工作顺序，具体实现、网络来源、商家合同和生产发布仍按对应任务范围开展：

1. measurement-baseline：M0；盘点/校验既有事件并完成基线。
2. trust-and-ranking：M1；评分方法验证、商业/自然隔离、纠错及关系披露。
3. demand-and-decision-mvp：M2/M3 基础；从需求到可解释比较及工具。
4. quality-and-discovery：M4；页面族质量、SEO/GEO 样本和观察。
5. fixed-sponsorship-pilot：M5a；单一固定交付模式及报告。
6. owned-sites-referral：M5b；用户指定我方站点接入与分账效果。
7. merchant-growth-loop：M6；Feed 健康、效果报告，再按需求建后台。
8. purchase-agent-expansion：M3 扩展；在可靠数据基础上完成个性化代理，复用既有比较。
9. data-product-discovery：M7；先验证外部需求，再实现许可内的数据产品。
10. M8 检查并入每份清单；不单独先做大型自治平台。

M4 观察可与 M5a 小范围试点交错；不以搜索排名达到某名次作为首次商业交付前提。商家增长和选购代理的早期实验纳入前期里程碑，避免长期只建设底座。
