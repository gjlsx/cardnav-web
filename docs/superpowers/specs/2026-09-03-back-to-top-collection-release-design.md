# 右下回顶、数据更新与发布设计

## 目标

为 AIGATE 的所有公开页面提供统一的回到顶部入口；用当前已批准的 Crawlee allowlist 更新本机数据并 merge/import；随后将该构建和本机运行库发布到 VPS。

## 已确认设计

- 回顶入口使用右下角固定悬浮按钮，而不是页尾按钮；滚动超过一个视口高度前保持隐藏。
- 点击使用 `window.scrollTo({ top: 0, behavior: 'smooth' })`，按钮为原生 `<button type="button">`，具备中文无障碍名称。
- 按钮和逻辑接入 `PublicPage.astro` 与 `public-shell.js`，因此所有普通公开页面共享；Guide 的独立滚动容器不强行加入，避免和文档阅读器滚动语义冲突。
- 数据更新只运行 `catch.config` 已登记的五个公开来源，固定并发 1；先写 raw，再由人工明确执行 merge/import 写本机运行库/公开快照。
- 一旦采集出现来源失败，不对该批次执行 merge/import；不跟随站外链接、不处理登录、挑战或验证码。
- 发布只通过 `publish_ai_lovemoney.py` 完成，保留服务器 `.env` 与 LikeShop 8086/8090/8095；生产不运行采集器或定时任务。

## 验收

1. 自动测试覆盖悬浮按钮标记、初始隐藏、滚动显示与平滑回顶行为；3101 的长列表页面可在浏览器点击回顶。
2. 采集输出包含一个真实 raw 批次且无失败，随后 merge/import 成功；3101 中转页面显示更新后的本地数据。
3. 发布后，旧域 HTTP/HTTPS 是 308，新域页面可在真实浏览器打开，LikeShop 三端口返回 200，且无生产采集器/定时任务。
