# p002 MySQL 运行时改造

应用运行时只能使用 `mysql2`，不得再依赖 `pg`。MySQL 默认指向本机 `ailovemoney`，环境变量使用 `MYSQL_HOST`、`MYSQL_PORT`、`MYSQL_USER`、`MYSQL_PASSWORD`、`MYSQL_DATABASE`。初始化必须幂等创建公开站点使用的快照、商店、网关、官方价格和排行榜表。所有公开读取与提交函数必须采用 MySQL 语法并在空库可运行。

验收：MySQL schema 集成测试、所有 store 导出函数的空库 smoke test、TypeScript 检查均通过；不提交数据库密码。
