## 明确排除

- 不读取登录后、付费、绕过验证、反爬或受限接口；不规避 robots、条款、频率限制或访问控制。
- 不将公开参考样例标为“实时”“保证”“推荐购买”或“本站售卖”。
- 不把第三方图片、整页截图或热链商标作为生产商品素材。若保留页面截图，只用于本地审计证据，不作为公开站资产。

- 不改 LikeShop 项目、端口 `8086`、`8090`、`8095` 或其部署。
- 不把 MySQL 密码、SSH 登录信息、数据库导出文件、令牌或完整外部响应写进仓库、任务日志或提交。

## 当前运行与数据库约束

- 本机开发与导入：MySQL `ailovemoney`；连接信息只能从现有本地 `.env` 读取，不能写入代码或文档。
- 数据库方向：MySQL 是唯一运行时数据库，PostgreSQL 已弃用；任何本次 schema/脚本不得重新引入 PostgreSQL。
- 公开页面当前优先读取 `public_snapshot_entries`，没有对应快照时再读取实体表。因此样例入库必须校验实体表与页面读取快照的一致性，不能只写“看不到的表”。
- 生产独立站：`ai.lovemoney.live` 由 Apache 80/443 反代至独立 Node 服务；发布仅更新该站构建与它的 MySQL 数据，不得触碰 LikeShop。
- 发布后验证：真实 DNS/host-header 的 `https://ai.lovemoney.live`、HTTP 80 响应、目标页面样例可见，以及 `http://dtch.yg2022.top:8086/shop/`、`http://dtch.yg2022.top:8090/mobile/`、`http://dtch.yg2022.top:8095/admin/` 仍可访问。

公开参考页只作为事实结构和少量短字段样例来源。采集记录需要可追溯，不应保存整站 HTML、登录态、个人资料或不必要的原文。价格、库存与更新时间在展示时一律说明为采样时的参考值。未来任何自动化前，必须由用户确认每个来源的允许范围、条款/robots 结果、频率、字段名单和数据保留期。
