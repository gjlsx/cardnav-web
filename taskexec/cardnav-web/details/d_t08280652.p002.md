# p002：可追溯 MySQL 样例数据

依据 p001 审计，完成最小、向后兼容的 MySQL schema 更新和幂等样例脚本。样例应覆盖至少：标准卡网/订阅产品、商家/渠道、价格/币种、库存或供给状态、来源 URL、采样时间、参考样例标志；可用公开参考站展示的 API 中转站/模型覆盖字段补足网关列表，但不得虚构可用性、真实响应时延或价格。

实现要求：

- 通过已有 `.env` 连接本机 `ailovemoney`，不得将秘密写入命令输出、代码或文档；脚本可重复运行且不制造重复数据。
- 只插入少量、明确命名为 reference sample 的数据；所有常量置于单一可审阅的样例定义中。
- 实体表和 `public_snapshot_entries` 保持页面可见数据的一致性；不能覆盖不属于本次样例的历史键。
- 添加针对 schema/样例契约的最小测试；输出匿名化的行数与来源数校验。

验收：重复运行脚本后数量稳定，MySQL 表和公开页面读取数据都含追溯字段；现有页面和测试不回退；不涉及远程数据库写入，生产写入留在 p003 的发布步骤。
