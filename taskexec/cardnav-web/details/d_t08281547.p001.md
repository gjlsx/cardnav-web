# p001 三语导航与公开入口改名

## 实施

在 `src/i18n/zh.ts`、`en.ts`、`ru.ts` 与所有使用这些用户可见字符串的页面中，将导航和对应入口改为：zh `中转网站 / 官方网站 / 帮助`，en `Gateway sites / Official sites / Help`，ru `Сайты-шлюзы / Официальные сайты / Помощь`。不改任何 href、路由文件或已有帮助 Markdown 正文。扫描首页卡片、SEO 标题和旧 `openGuide`/`buyingGuide` 语义，避免导航已叫帮助而入口仍称向导或排行。

## 验收

- `/llm-gateway`、`/official-price`、`/guide` 路由仍可打开。
- 三种 locale 的桌面和移动导航都显示新名字；从首页点击可进入原路由。
- 更新必要快照/文案测试；执行相关测试、类型检查或构建，并用浏览器记录真实入口证据。
