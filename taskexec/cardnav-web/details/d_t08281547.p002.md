# p002 标准商品目录与卡网聚合默认视图

## 实施

最小化扩展 MySQL 和 `src/database.ts`：创建 `catalog_products`（slug、platform、product_type、显示名、aliases）和未知别名的人工待确认队列；既有参考样例关联权威 SKU。为报价补足自然唯一约束 `(source_id, standard_product, site_id)`，同时保持迁移对现有 MySQL 兼容。把 `reference_data_sources.is_sample` 默认改为 false；来源 URL 与商家官网 URL 分离，未核实官网设空；种子绝不改 `popular-search-terms`。packed DTO 若扩展字段则升级版本或实现按长度兼容，并加覆盖测试。

将 `/shops` 默认改成按标准 SKU 聚合：每 SKU 一个结果，按优先级的有效报价算最低参考价并统计渠道数和库存，样例标记与采样时间可见；点击/切换才显示商家渠道。首页热门卡网复用同一聚合 DTO。无商品/商家购买链接，不复制第三方页面皮肤。

## 验收

- 本机 `ailovemoney` migration/seed 重跑无重复，参考记录、权威 SKU、待确认队列和快照计数合理；热搜快照不变。
- 聚合的同优先级重叠保留最低价；初始站点评分为 50，排序预留但不提前做完整评分系统。
- 测试覆盖 packed 兼容和聚合规则；浏览器从首页进入 `/shops`，默认显示商品聚合并可下钻；无购买外链。
