# p003 中转网站公开参考样例

## 实施

用现有架构的最小表/DTO 扩展为 4–8 个来源明确的网关样例站、模型覆盖和少量公开可见模型价格，实体表与 `public_snapshot_entries`（`gateway-sites`、`gateway-models` 和实际消费 key）一致。采集结构允许保留白名单内的平台族、模型数、支付/区域/状态标签、字段来源与观测时间；公共列表只显示站名、覆盖模型、模型数、评分、采样时间和样例提示。每一行带 `is_sample`、采样时间、来源页；邀请链接为空，不能编造延迟、可用性、官网 URL 或购买引导。`/llm-gateway` 默认按 `score` 降序，支持按模型筛选，首页中转模块显示样例与非实时提示。

## 验收

- 本地 seed 幂等，且仅影响样例数据。
- `/llm-gateway` 和首页相关模块有可见非空样例；至少一个模型筛选能展示按评分降序的支持站点；中文/英文/俄文文案不产生实时保证。
- 从首页导航进入页面的浏览器验证、相关测试、类型检查/构建通过。
