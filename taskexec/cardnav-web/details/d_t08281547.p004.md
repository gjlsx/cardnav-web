# p004 官方网站公开参考样例

## 实施

以最小 schema/DTO/seed 支持 ChatGPT、Claude、Gemini、Grok 等至少四种官方产品，每种 2–3 个地区的公开参考套餐价；实体表和 `official-price-catalog`、`official-prices` 快照同步。显示必须带来源、采样/参考样例/非实时语义，不能声称官方实时价保证。首页官方网站模块与 `/official-price` 都要有数据。

## 验收

- seed 可重复执行且不动非样例数据/热搜快照。
- 首页和 `/official-price` 通过真实导航可见样例行与正确提示。
- 相关测试、类型检查/构建和本地 MySQL 核验通过。
