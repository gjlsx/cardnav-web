# p004 官方网站公开参考样例

## 实施

以 CardNav 的 `https://cardnav.xyz/official-price/chatgpt-pro-5x` 为信息层级参考，最小 schema/DTO/seed 支持 ChatGPT、Claude、Gemini、Grok 等至少四种官方产品，每种 2–3 个地区的公开参考套餐价；实体表和 `official-price-catalog`、`official-prices` 快照同步。`/official-price` 有计划切换；每个计划详情显示地区、本地标价、币种、折合价、采样时间和两个内部入口：关联卡网商品、支持映射模型族的中转网站。显示必须带来源、采样/参考样例/非实时语义，不能声称官方实时价保证。首页官方网站模块与 `/official-price` 都要有数据。

## 验收

- seed 可重复执行且不动非样例数据/热搜快照。
- 首页和 `/official-price` 通过真实导航可见样例行与正确提示；从一个计划详情点击可看到内部卡网结果及按评分排序的中转站结果，不访问第三方购买页。
- 相关测试、类型检查/构建和本地 MySQL 核验通过。
