## Work

以幂等、只增列/表的方式在本地 MySQL `ailovemoney` 创建 p011 的 collection/override/activity 表。`collection_staging_observations` 是唯一 staging 表：保留其已有行与现有 CLI/测试入口，增量添加 `record_key`、`record_kind`、质量/发布状态、raw/run 关联及所需索引；禁止创建 `collection_staging_records` 或双写。通过项目 `.env` 的 `MYSQL_*` 连接，不打印连接字串、密码或响应敏感字段。迁移必须可重复执行；不删除既有 public 表或样例。

实现 repository：创建/结束 run；写入 raw payload/raw record；写入/按 run 读取 `collection_staging_observations`；写/读覆盖标志；写审计活动；清理 `captured_at < NOW()-INTERVAL 30 DAY` 的完整 `body`，保留其 hash、元数据与解析记录。迁移后旧 fixture staging 行仍可读取，且通过稳定键/状态的空值兼容映射，避免丢失既有结果。
