## Work

使用 `ttk.Notebook` 创建根 Tab：采集数据、网站配置、合作运维；采集数据内创建四个固定子 Tab。保留 `gui.py` 为单一启动命令并改为启动 `ConsoleApp`。实现复用的后台任务运行器：后台线程只产生事件，主线程用 `root.after` 更新控件；运行中禁用同一动作，完成/失败恢复；异常写可读日志而不是崩溃 GUI。

每个页面拥有独立 `ScrolledText` 日志视图和明确 page key；运行记录另写 `console_activity_logs`，重开后可按页加载最近日志。布局固定为上方操作/状态、中部左侧列表加右侧详情、底部日志；最小窗口和可拖动分栏不遮挡关键按钮。不得将采集 Tab 的日志混进运维或网站配置 Tab。

## Acceptance

- 无数据库时可启动 shell 并在日志显示可操作错误；有数据库时能读取历史活动。
- 单测证明后台事件经 UI 队列投递、同一 action 不并发、日志按 page key 隔离。
- 实际启动窗口可看见三根 Tab 和四个采集子 Tab。
