## Work

实现网站配置 Tab：用实体类型选择器、全文/稳定键搜索、状态筛选显示当前正式数据；右侧详细字段编辑对四类页面数据精确生效。保存时建立/更新 `ManualOverride`，在同一个 MySQL 事务更新目标正式表及它实际使用的公开快照；隐藏不物理 delete。解除手工覆盖只切标志，不从历史回填。

显示站点 score、来源 priority、是否样例、最后采样/发布/人工修改时间，但明确 score 与 priority 的差异。允许编辑 `site.score`（当前样例默认为 50），不允许在来源配置中编辑/派生它。所有动作写本 Tab 独立日志和审计。

## Acceptance

- 单元/集成测试证明按稳定键的单条编辑立即可被现有 `src/store.ts` 读取。
- 一个站点+SKU 覆盖不会影响其它站点同 SKU；隐藏记录不在网站查询返回。
- 不需要网页后台或新公开 API 才能完成管理动作。
