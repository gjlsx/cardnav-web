## Work

在合作运维 Tab 显示现有合作/中转站提交的审核队列、来源批准状态、最近数据质量异常、备份/发布健康状态。审核操作应把提交转换为可审阅来源登记或正式站点候选，不自动联网或自动公开。

提供本机 MySQL 数据导出、导入前预检、构建验证和遵循 `howtorunvpsnew.md` 的“发布到服务器”入口；只显示脱敏连接信息，不提供 SSH host/密码编辑器。预检是默认第一步，但二次确认（目标环境 + 明确动作）完成后，备份、恢复和发布必须调用发布指南规定的本机脚本/命令真执行；缺少该指南引用的本机安全凭据时明确失败，不退化为假成功。每个结果写本 Tab 日志和审计。禁止影响 LikeShop 8086/8090/8095。
