# p018 本地按来源调度与运行管理

## Files

- Create: `scripts/collection/console_lib/scheduler.py`
- Modify: `scripts/collection/console_tabs/collection_tab.py`
- Modify: `scripts/collection/collection_lib/repository.py`
- Test: `scripts/collection/tests/test_scheduler.py`

## Work

实现仅在 GUI 进程内生效的本地调度器，不创建 Windows Task Scheduler、服务或后台常驻进程。它按 `collection_sources.enabled/interval_minutes/max_items_per_run` 决定 due source；同一来源不得并发。GUI 支持启动/停止调度、手工运行、查看下次运行时间；关闭 GUI 时调度停止。

默认全部 source `enabled=false`。手工运行仍可执行 approved-source 的正常路径或 draft-source fixture 路径，但上限始终有效。失败采用记录状态与下一轮时间，不无限重试；调度产生的日志进入其实体子 Tab，不进入其它 Tab。

## Acceptance

- 可注入时钟单测覆盖 disabled 不调度、每来源独立间隔、上限、同源排他、停止后不继续运行。
- 启动总控台后不会自行启动调度或发生 HTTP。
- 没有 Windows 计划任务、cron 或生产端采集改动。
