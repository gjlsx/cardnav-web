# p021 本机 HTTP 验收数据回收

## 问题

`LiveMysqlHttpTests` 使用真实本机 MySQL 来证明 p013 的 raw 到正式数据流水线，但测试结束后保留 `p013-http` 和 `collected-p013-test.example` 的测试记录；发布脚本会导出本机库，因此可能把测试数据带入生产。

## 实施与验收

- 先添加一个会失败的断言：HTTP 测试完成后，本机正式表与 `shop-products` 快照不再含测试站点。
- 在同一个事务中删除该测试专属的 raw、staging、run 和正式记录，重建 shop 快照并提交。
- 不删除其他来源、人工数据或样例数据。
- 运行严格 ResourceWarning 的完整 collection 测试，并确认本机数据库不存在测试站点。
