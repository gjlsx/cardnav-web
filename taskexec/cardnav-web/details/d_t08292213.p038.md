# t08292213.p038：PriceAI 三类公开数据 Crawlee 浏览器采集入库

## 原始需求（用户已确认）

采集正式路线固定为 **Crawlee for Python + Playwright 浏览器**。新建与既有 GUI/网站运行时解耦的本机独立采集程序；现有零散采集实现保留但废弃，不删除、不从新 CLI 或 GUI 调用。

首个来源为 PriceAI，采集并入库下列三个公开入口；只访问这三个精确 allowlist URL，不跟随其中任意商家、官网或中转站外链：

| 来源 ID | 页面 | URL | 项目既有记录类型 | 来源等级 |
|---|---|---|---|---|
| `priceai-card-subscriptions` | 卡网订阅 | `https://priceai.cc/channels` | `RecordKind.SHOP_PRODUCT` | `aggregator` |
| `priceai-official-api` | 官方 API / Token Plan | `https://priceai.cc/official-api` | `RecordKind.OFFICIAL_PLAN` | `aggregator` |
| `priceai-transit-api` | 中转 API | `https://priceai.cc/api-transit` | `RecordKind.GATEWAY_SITE` | `aggregator` |

PriceAI 是聚合来源，而非下游官网或中转站自身 API，因此三者都必须保留 `aggregator` 来源等级并服从现有 PriceAI > CardNav > OpenPrice 的聚合来源优先级。页面内的账号、Cookie、验证码、订单、联系方式和购买/交付信息不解析、不入库；不绕过 robots、登录、人机验证、挑战页或访问控制。

## 独立程序职责

在新的独立 Python 包中保持下列明确分层（文件名可在实施时按现有命名规范微调，职责不得合并）：

1. **来源控制文件**：一个文件维护 1 个到 N 个站点/页面的来源定义、精确 allowlist URL、启用状态、记录类型、优先级、选择器/解析器键和上限。新增第 2、第 10 个站点只能新增配置/解析器注册，不重写调度与 MySQL 基础设施。
2. **独立页面解析文件**：按 `source_id + page_type` 从 Playwright 渲染后的公开页面提取白名单字段，构造项目既有 `SHOP_PRODUCT`、`OFFICIAL_PLAN`、`GATEWAY_SITE` 数据类/稳定键；不得新建平行业务 schema，也不得通过字符串计数把页面文本冒充记录。
3. **独立 MySQL 入库文件**：封装现有 repository/数据合同的读取、raw 写入、批次状态、merge/import 和运行库查询。一个 CLI 采集批次或常驻 worker 使用一个可复用 MySQL 连接/会话贯穿读取、批量写入和事务；不得每条记录或每条 SQL 开关连接。连接空闲复用时长设为可配置 `connection_idle_ttl_s`，默认 600 秒；超时、已断链或明确瞬态连接错误才有界 ping/重连，事务失败先回滚，进程退出时关闭一次。
4. **CLI 与 worker 文件**：CLI 能检查配置、列出来源、对一个或多个来源执行浏览器采集、查看 raw batch、显式 merge/import、启动/停止默认关闭的单例 worker。worker 每 10 秒串行处理一个 `raw_completed` batch，不发采集 HTTP；入库使用既有 24 小时新鲜度、手工闸门和来源优先级事务。

## 数据流与入库

`PlaywrightCrawler（并发上限 1） -> 已批准来源原始响应 -> collection_raw_payloads / collection_raw_records -> 独立 merge/import worker -> 既有运行时实体表和 public snapshots`。

“采集入库”必须同时验证三段：三个来源的 raw 审计记录落入本机 `ailovemoney`，显式 merge/import 将可映射记录写入既有运行时表/快照，网站读取到非 fixture 的运行时结果。一个来源失败、页面结构变化或遇到挑战页时，只记录失败/保留旧运行时数据，不能发布空快照或删除已有数据。

## 实施与验收

- 安装并锁定 Crawlee、Playwright 及浏览器运行依赖；新程序仅通过 `PlaywrightCrawler` 获取页面，默认关闭所有真实来源。
- 为三个页面各保存最小脱敏 fixture，并对解析字段、稳定键、重复行、无价格/缺货、原始记录白名单和禁止字段写单元测试。
- MySQL 集成测试验证单连接批次、参数化批量写入、事务回滚、600 秒空闲复用/失效重连逻辑，以及 merge/import 的 24 小时优先级不回归；测试数据必须清理。
- 提供 CLI 帮助与 dry-run；人工明确执行的真实 PriceAI 三来源采集仅写本机 MySQL，随后显式 merge/import，记录 batch ID、记录数、跳过/失败原因和运行时写入数。
- 旧采集入口保留并标记 deprecated；新 CLI/GUI 不引用它。不得删除旧文件、迁移生产数据库、启用无人值守采集、运行生产服务器采集器，或跟随下游链接。
