# t08292253.p002 PriceAI 三页浏览器解析与数据类映射

## 范围

独立 parser 文件按 `source_id` / 页面类型解析 Playwright 取得的 HTML 或页面快照，转换到既有 `scripts/collection/collection_lib/contracts.py` 定义的对象与稳定键。不要由解析器写 MySQL，也不要创建平行 DTO/schema。测试 fixture 只可记录最小人工构造的无敏感 HTML，不保存真实响应全文。

## 验收

对三个页面类型分别测试字段提取、空值、重复项和稳定键；确保 parser 产出只能是对应的 `SHOP_PRODUCT`、`OFFICIAL_PLAN`、`GATEWAY_SITE`。
