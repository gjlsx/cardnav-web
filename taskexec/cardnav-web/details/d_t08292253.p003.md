# t08292253.p003 长连接 MySQL raw 持久化与独立合并 worker

## 范围

新增独立数据库文件，使用 MySQL 参数化访问与既有 repository/merge/import 合同，将浏览器 capture 和 parser 结果落入固定 raw 数据流。连接只在活跃 CLI/worker 中复用，`connection_idle_ttl_s=600` 可配置；每个 raw 批次仍必须有独立事务和异常回滚。worker 仅在显式启动时运行，进程内 singleton、单线程、每 10 秒轮询，禁止与 GUI/生产调度绑定。

## 验收

用 fake connection / 既有测试替身验证连接重用、TTL 关闭、异常重连、事务界限和同一时刻只运行一个 worker；测试不得需真实网络。
