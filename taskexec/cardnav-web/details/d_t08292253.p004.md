# t08292253.p004 独立 CLI 与受控采集流水线

## 范围

实现简洁 CLI：`check-config`、`list-sources`、`collect --source <id>|--all`、`list-raw`、`merge-once`、`worker`。`collect` 必须只经 Crawlee Playwright、仅从来源登记读取 URL、在一批次内落 raw；不提供任意 URL 参数，也不调用 legacy 采集入口。worker 默认不启动，只有 CLI 显式命令可运行。

## 验收

使用依赖注入/替身测试命令选择、allowlist、防止多 worker、raw-to-merge 调用顺序和失败退出；所有浏览器并发固定为 1。
