# t08300235.p006 中转站标准模型白名单与 CardNav 详情采集

## 已批准来源和固定边界

- `https://priceai.cc/api-transit/models` 是本轮唯一的标准模型目录。采集它的公开页面内容并在同一批次建立允许模型集合；该目录本身不作为模型排行或站点数据发布。
- `https://cardnav.xyz/llm-gateway` 是唯一的 CardNav 列表入口。仅可从该列表已渲染的同域 `https://cardnav.xyz/llm-gateway/<slug>` 链接发现并访问一层站点详情；禁止跟随其外部“打开”链接、模型页链接、广告、登录、验证码、挑战页或其它路径。
- URL 许可必须由代码固定：PriceAI 精确模型页、CardNav 精确列表页、以及由列表 DOM 发现且匹配 `/llm-gateway/<safe-slug>` 的 CardNav 同域详情页。`catch.config` 只能选择登记来源和上限，不能添加 URL。

## 数据合同

- 标准模型 ID：删除首尾空白，把连续空白压为一个空格，Unicode casefold，再将空格替换为 `-`。例如 `GPT 5.6 Luna` -> `gpt-5.6-luna`。
- 只保留规范 ID 在本次 PriceAI 标准模型集合中的 CardNav 详情模型；CardNav 列表的分类标签不当作模型入库，未命中白名单的详情模型也不写入运行时。
- 一个 CardNav 详情对应一个既有 `gateway_site` 稳定键。站点公开名称、summary、类型/模型族、站点来源 URL、详情中可见评分、可访问性、平均响应与模型价格白名单字段都只写 raw payload/record 的白名单字段。
- merge/import 必须在同一既有事务中写 `gateway_sites`、每站多条 `gateway_model_coverage`、有公开数值时的 `gateway_model_prices`，再刷新 `gateway-sites` 和 `gateway-models` 快照。不得创建平行 schema、直接写运行时或把 PriceAI 模型页当成模型排行。

## 自动化验收

先增加最小脱敏 fixture 测试并先观察失败，覆盖：模型名称标准化；仅白名单模型保留；列表详情 URL 许可和外部 URL 拒绝；一个详情解析为一个站点及多条模型/价格；publish 后覆盖/价格/快照包含标准 ID。随后运行 Crawlee focused tests、legacy collection tests 和 Astro typecheck。
