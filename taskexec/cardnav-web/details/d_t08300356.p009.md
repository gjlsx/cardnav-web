# t08300356.p009 中转站排序、更新时间与福利详情

## 目标

完成 AI LoveMoney 中转站列表与详情页的本轮产品调整，并保持公开采集的 raw -> merge/import -> runtime/snapshot 生命周期不变。

## 已确认需求

1. 列表默认按评分降序；评分相同按模型数量降序，最后以站点名稳定排序。
2. “支持模型”右侧增加“最近刷新”列；评分提示改为“评分系统根据模型数量、价格、用户评价、稳定性等多维因素决定，仅供参考，即将上线。”
3. 列表只保留站点名和“详情”到站内详情页的入口，删除相邻外站“打开”按钮。
4. 详情页展示“可用福利”和“区域”。福利、福利跳转 URL、地区均保存在 `gateway_sites` 并能由本地站点配置页手工编辑。
5. 没有福利时显示“你来迟一步，福利领完了”；不显示“福利入口”。如站点有外站 URL，详情页显示“领完福利前往”并前往该外站。
6. 详情页“提交建议”直达既有 Telegram 群链接。

## 范围与约束

- 不采集、登录或访问商家外站；福利仅为人工维护的公开展示字段。
- 新字段不能被采集导入覆盖已有手工维护值。
- 评分公式本轮不上线，只调整说明与确定性排序。
- 通过数据库安全迁移、public snapshot 和本机 3101 页面验证；不记录数据库凭据。

## 验收

- 自动测试覆盖排序、字段/编辑通路、链接语义与文案。
- 本地 3101 浏览器截图由后续 p010 验收，未通过不得将本轮任务宣告完成。
