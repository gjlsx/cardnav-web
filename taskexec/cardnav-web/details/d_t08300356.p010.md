# t08300356.p010 中转站福利功能 3101 浏览器验收

## 目标

仅以本机真实 `http://127.0.0.1:3101/` 浏览器页面作为最终验收。

## 验收条件

1. `/llm-gateway` 截图可见“最近刷新”列、新评分提示，且首行排序满足评分后模型数的规则；列表不再有“打开”。
2. 从列表点击站点名或“详情”进入站内详情页，截图可见“可用福利”“区域”“你来迟一步，福利领完了”“领完福利前往”“提交建议”。
3. 通过 DOM 链接属性确认“领完福利前往”只指向该站点外站，且“提交建议”指向既有 Telegram 群；不实际打开外站。
4. 截图和可复核 URL/可见事实写入 QA 报告。任何一项未通过，任务保持 doing 并继续排查。
