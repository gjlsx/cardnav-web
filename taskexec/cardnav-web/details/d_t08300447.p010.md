# t08300447.p010 GitHub 中转站实时参考榜合同

## 已批准来源与语义

- 唯一网络入口：`https://raw.githubusercontent.com/hvoyai/awesome-ai-api/main/data.json`。
- 固定 `source_id=hvoyai-awesome-ai-api`，`RecordKind.GATEWAY_SITE`；README、`index.html` 不另采、不作为双来源。
- 只白名单：`updatedDate`/`generatedAt`、`rank`、站名、禾维同域站点 URL、模型数量/厂商、在线率、延迟、用户评分/人数、支付方式、退款、发票。
- 上游 `rank` 保留为 `source_rank`，名称“中转站实时参考榜”；它不是 AIGATE 分数，也不是模型价格或模型能力排名。

## 验收

1. 代码 allowlist 和 fixture 测试同时锁定精确 URL、JSON 内容类型、字段及缺字段处理。
2. 读取 robots/公开访问条件；无法合规访问则不发真实采集，任务记明原因。
3. 稳定键优先解析禾维同域 URL host；没有有效 host 的记录只审计、不入运行时。
