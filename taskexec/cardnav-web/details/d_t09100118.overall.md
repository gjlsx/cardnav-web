# 外部榜单引用与最小计量 Implementation Plan

> 执行者：先等待 wind 确认本 tasklist；之后按 taskexec 与 executing-plans 逐项执行，不自动派子代理。该文件是任务 Detail，不是第三份战略或路线图。

## Goal / Architecture / Tech Stack

Goal：用现有榜单入口提供可核验的外部评分引用与可复查的站内路径统计，为后续自测评分飞轮建立第一块可用产品。
Architecture：沿用 Astro/Node、既有 MySQL runtime/snapshot 读取；引用分数与来源一同展示。自有计量是同一应用内独立事件接口/统计表，不写采集表、商品热度或评分。站点采集仍只有既有 raw → 独立 merge/import → runtime/snapshot。
Tech Stack：现有 Astro、TypeScript、浏览器 JavaScript、mysql2、Node test/tsx；本单不安装新分析平台或测评框架。

## 用户要求与决策

- 根本目的：可持续自扩展的可信 AI 比较、排名和导流网站；SEO/GEO 是手段。
- 对标成熟竞品，同时有几个自己的特色，不发展成全面平台工程。
- 评分是产品要求；先引用外部榜单，再推进本人或第三方开源项目自测。C→B 是顺序，不是对两道题分别选项。
- 自有统计负责站内活动；Google 与各内容平台的统计引用对方可取得的数据。
- 获客集合：Google、QQ/Telegram 公开群、小红书、X、Bilibili、Substack、YouTube。没有承诺本单同时运营所有渠道。
- 固定赞助、付费排名、广告及后续我方商业站导流方向不变。付费/自营不得改变自然分数、自然候选或自然排序。
- 用户尚未指定自测仓库、调用目标、费用和确切新榜单采集许可；这些属于后续运行审批，不能被本单猜定。
- 本单的模型能力引用和既有中转参考不是互相替代的评分。完整双榜体系/商家自评分仍是 M1 工作，不因本次顺序确认视为方法获批。

## 三种首批范围与推荐

| 方案 | 收益 | 代价/取舍 |
|---|---|---|
| A 仅做计量 | 最小工程量 | 缺少可见评分产品改进，不符合最新强调 |
| B 引用可信化＋一条路径计量（本单建议） | 修正现有真实缺口，能展示和验证；为自测结果保留来源语义 | 不交付新榜全量采集、自测引擎、全站评分或真实增长结果 |
| C 引用＋自测＋多渠道自动运营 | 同时覆盖长期愿景 | 来源、费用和实验方法未定，投入过大；放在后续清单 |

本单选 B 作为待用户确认的实施建议；用户当前已确认的只是 C→B 的业务顺序。不是把方案表里的 B 再映射成旧战略字母。

## 自有统计建议与参数（随清单一并确认，尚未实施）

首批只用 sessionStorage 随机匿名会话标识，不用 cookie/localStorage 长期识别，不采 IP、UA、搜索原文、完整 referrer 或外跳 URL；关闭标签页后不追踪回访。仅在用户允许本会话统计后发送；支持拒绝统计/存储不可用时不发送，绝不阻断浏览/外跳。会话标识不是自然人，不能声称每周去重用户。

src/measurement-config.ts 统一读取服务端环境变量；.env.example 只记录公开配置名与默认值。以下是建议技术限额，不是已批准经营目标：

| 键 | 默认 | 验证 |
|---|---|---|
| MEASUREMENT_ENABLED | false | 缺值/false 不装载追踪、不写事件 |
| MEASUREMENT_ENVIRONMENT | local-test | 服务端标记，仅 local-test/production；报告按实际存储环境过滤，客户端不能自报 |
| MEASUREMENT_RETENTION_DAYS | 14 | 正整数；CLI 清理仅过期统计记录，先 dry-run，显式 --apply |
| MEASUREMENT_MAX_EVENT_BYTES | 2048 | 流式读取时计数，超限 413，不能只信 Content-Length |
| MEASUREMENT_MAX_EVENTS_PER_DAY | 10000 | 同库原子日计数上限，多进程一致；超限拒收并在报告标不完整 |

香港自然周是已有指标口径，不是新增业务阈值；事件时间以服务端接收 UTC 记录，按 Asia/Hong_Kong 分桶。单次事件重试复用 eventId 去重；每日名额消耗只算新接收事件。测试/无效事件不计业务指标；限额不能宣称为完整反机器人系统。

不接真实访客前须复核隐私告知/授权方式与生产安全限额，本单默认关闭，无生产启用任务。指标是观测会话/路径，不是签约计费事实或成交。完整 M0 北极星 unavailable；统计不可用不记为 0。
