## Interfaces

src/leaderboard-evidence.ts 导出：
- parseReferenceScore(value: unknown): number | null。
- safeEvidenceUrl(value: unknown): string | null；仅接受无用户名/密码的公开 HTTP(S) URL，拒绝 javascript/data/file、本机/私网和非法地址；只生成链接，不请求其内容。
- evidenceGroupKey(row: { sourceId: string; sourceUrl: string; sourceGroupSlug: string; sourceBoardSlug: string; taskSlug: string; sampledAt: string }): string，按来源＋原榜＋原始快照时间分组，不能跨版本拼一个总榜。
- buildReferenceEvidence(row: PublicModelLeaderboardRow)：返回 sourceLabel、sourceUrl、score、rank、sampledAt、status（sample/reference/unverified）、groupKey、methodStatus（not-recorded，除非原记录确有可核验方法）。不要通过域名自动产生“已验证”状态。

src/leaderboard-reference-policy.ts 仅登记 p001 已核验的现有来源使用方式（sourceId、sourceUrl、usageStatus=reference/link-only/sample、证据 QA 链接）；未知来源默认 link-only，不自动注册 URL 或启动采集。buildReferenceEvidence 消费该政策；link-only 的公开 displayScore/displayRank 必须为空，提供安全原榜链接与说明。sample 独立显示样例。reference 仅说明有引用依据，不宣称测试结论正确；方法缺失仍提示限制。API 也不能泄漏 link-only 的原分数。不把许可疑问留给 UI 临时猜测。

PublicModelLeaderboardRow.score 改为 number | null；缺失/无效 rank 也不得产生自然第 0 名，公开显示 unknown。原有效 rank 只表示来源名次。保持 DTO 向后读取，snapshot 与 SQL 必须同语义；API/调用方的编译修正在 p003 中完整验收。

```ts
export function parseReferenceScore(value: unknown): number | null {
  if (typeof value !== 'number' && typeof value !== 'string') return null;
  if (typeof value === 'string' && !value.trim()) return null;
  const parsed = Number(value);
  return Number.isFinite(parsed) ? parsed : null;
}
```
