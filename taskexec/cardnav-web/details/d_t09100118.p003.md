## Steps

- [ ] 先写失败断言：首屏和动态行都有来源链接/时间/样例或未核验提示，score=null 显示“未提供”而不出现 0.00，score=0 显示真实零。
- [ ] 使用 p002 helper 替换直接 item.score.toFixed(2)；浏览器不得先 Number(null)。最小格式逻辑：

```ts
const scoreText = item.score === null ? labels.notProvided : item.score.toFixed(2);
```

- [ ] 每行/每独立原榜区明确“外部参考评分”；显示转载方与可用的原发布方、原榜入口、原采样时间。方法未知显示“方法/量纲未核验，请查看原榜”，不能新增虚假“本站实测”。
- [ ] sourceUrl 不安全时不生成可点击链接；样例保留醒目标识；不把首次载入此页日期冒充原榜更新日。没有真实可用数据时保留诚实空态与安全原榜链接，不补造分数。
- [ ] 多原榜不混合数值排序，保留原名次及独立组标识；分页接续也必须保留这些标识，不能重复/漏组。保持现有任务页签、/model-leaderboard 入口、canonical 和 zh/en/ru 路由。
- [ ] 现有商家/网关关系路径沿用 leaderboardRelatedPaths，不根据任意显示名猜站点。不新增付费名次；不宣称下游网关页已经独立自然榜。
- [ ] pnpm exec tsx --test test/leaderboard-evidence.test.ts test/leaderboard-evidence-ui.test.ts test/model-leaderboard.test.ts；pnpm run typecheck。
- [ ] 执行前检查 pnpm exec astro dev status；从 3101 首页导航到排名参考，查看任务页、来源提示、加载更多和已有比较入口，桌面/移动及三语取证。不必真实点击到商家消费页；外部榜链接可在许可内只读核验。
- [ ] 自审并记录真实入口、数据状态、截图/网络结果、未覆盖项，再提交。
