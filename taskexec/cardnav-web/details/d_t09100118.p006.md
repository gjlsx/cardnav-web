# p006 周报 CLI 与平台汇总引用

Depends：t09100118.p004、t09100118.p005。

## Files / Interfaces

Create：test/measurement-report.test.ts。
Modify：scripts/measurement-report.ts（扩展 p004 的同一 CLI）、src/measurement.ts（纯周窗/报告归约）、src/store.ts（窄范围只读统计/过期清理方法）。
不用 Dashboard、第三方账号连接、群数据抓取或第二数据管道；外部运营汇总只作为本地报告附件，不写公开数据表。

命令合同：
- pnpm exec tsx scripts/measurement-report.ts --week-start 2026-09-07 --environment local-test
- pnpm exec tsx scripts/measurement-report.ts --week-start 2026-09-07 --environment local-test --external-file D:/approved-reports/platform-summary.json
- pnpm exec tsx scripts/measurement-report.ts --cleanup --dry-run
- pnpm exec tsx scripts/measurement-report.ts --cleanup --apply

以上 external-file 是用户提供的操作示例路径，不是已存在文件。程序只读取明确指定的 JSON，不下载 URL；缺文件报错，不偷偷创建示例或发请求。默认 stdout 输出聚合 JSON，不导出会话 ID/事件明细。环境 local-test 在报告中醒目标明；生产不在本单运行授权内。

输入外部项 schema：platform（同 channel 枚举中具体平台，不含 direct-or-unknown）、periodStart、periodEnd、timezone、metric、value（非负有限数）、sourceUrl（平台公开报告说明或用户自己的后台来源说明，不含令牌）、exportedAt。

--environment 是过滤已存储环境，不是给查询结果随便贴标签；测试与 production 事件分别统计，不允许跨环境相加。所有建表、报告和清理命令复用 p004 本机 DB 目标核对；不得因此启用远程连接。清理按环境与截止时间限定，删除条数可复核。
允许 metric = impressions / views / clicks / reads；拒绝账号、邮箱、用户级行/任意嵌套对象。文件技术上限 1 MiB（集中命名常量 MAX_EXTERNAL_REPORT_BYTES 并测试），不把截图 OCR 或推估冒充平台导出。外部项为“用户提供、未独立核验”，重复行按 platform+period+metric+sourceUrl 拒绝而非相加。

## Output contract

weekStart、timezone=Asia/Hong_Kong、environment、observedSessions、eventsByName、channelSummary、pathSessions、coverage、externalMetrics、northStar=null、northStarReason。
pathSessions 仅统计同会话按序出现的 comparison_enter → comparison_interact → outbound_click（outbound 发生在目标报告周，前置事件若超出保留/观测范围则不可串联）；称“观测到的比较交互后外跳会话”，不称“可信比较完成用户”。

同一周跨渠道/位置/目标分项不直接相加得总人数；跨标签/设备不合并。未知来源单列。点击不等于成交，平台曝光不等于站内会话。未接入的外部平台为 unavailable，不补零。
coverage 记录最早/最晚收到事件、运行开关/保留窗口可确认情况及日配额拒收；无法知道总访客或被拦截比例时明确 unknown，不能伪造覆盖率。
