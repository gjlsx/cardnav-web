# t09122137.p003：在中转站列表与模型详情明确渲染两类结果

## Goal

把 p002 的两条数据路径反映到真实用户界面：独立、明确标记的赞助展示与完整自然榜并存，且任何表格默认排序、sticky、筛选或浏览器动态刷新都不再把赞助作为自然结果的排序条件。

## Required behavior

- 主列表与模型详情都要覆盖 SSR 首屏及客户端动态加载路径。
- 赞助区使用文字标签（如现有 locale 对应的“赞助/合作商家”）和结构化区域/标题，不能只凭颜色、图标或 CSS class 区分。
- 自然表中删除赞助隐式置顶排序；用户筛选、正常排序、键盘导航和读屏语义仍可用。
- 自然榜必须完整可见；不能以隐藏、折叠、截断或默认只显示付费项的方式降低自然结果可得性。
- 同一站点如果自然进入自然榜且另有赞助展示，两个位置必须各自语义明确，不能暗示自然名次因购买而上升。

## Acceptance

- 覆盖 p001 确认的所有入口，并用组件/集成测试证明动态加载路径采用 p002 的隔离结果。
- 不改商品商店的 sponsored pinning；若共享组件确实需要安全修复，记录证据并保持变化最小。
