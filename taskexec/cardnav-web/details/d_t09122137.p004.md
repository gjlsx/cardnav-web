# t09122137.p004：补齐来源、合作关系与纠错披露

## Goal

为自然结果、公开来源参考、赞助/关联关系和纠错反馈建立一致、简洁、用户可见的披露，防止付费展示或上游分数被误读为 AIGATE 自有排名结论。

## Requirements

1. 在 p001 确认的列表/详情入口提供可见说明：自然榜与赞助展示相互独立；赞助不改写自然评分或排序。
2. 对 Hvoy 等上游公开 rank/score 说明其为来源参考；不得使用“本站综合评分”“AIGATE 评分”等误导表述，除非未来独立任务建立可审计公式。
3. 任何付费外部目标需同时呈现可见赞助标签，并有 `rel="sponsored noopener noreferrer"`。自然来源引用不可错误附为 paid/sponsored。
4. 增加或复用一个清晰的纠错/反馈入口。若无后端，不得声称自动受理、SLA 或已建立工单；可用现有联系方式、反馈页或邮件链接。
5. 中、英、俄 locale 的语义一致，不要求逐字翻译；不得把赞助标签翻译成“推荐”或“自然排名”。

## Non-goals

不建立广告订单、商家后台、支付、合同到期、纠错工单系统或埋点；不改变外部采集链接和来源 allowlist。

## Acceptance

- 提供文案定位、三语渲染测试和链接属性测试。
- 披露在桌面及窄屏可见且与对应列表/赞助块邻近，不能只藏在不相关页脚。
