# t09122137.p005：自然榜不受赞助影响的回归与浏览器验收

## Goal

以自动化测试与实际本地浏览器，证明 M1 的核心信任红线成立，并记录可复现证据。此任务不部署、不执行真实采集、不启动生产统计。

## Verification matrix

| Case | Expected result |
|---|---|
| 同一自然输入切换 sponsor | natural 集合、顺序与自然分数不变；仅赞助展示集合变化 |
| 无 sponsor | 结果不出现空白/错误赞助区，原有自然排序无回归 |
| 主列表与筛选/动态刷新 | 赞助不进入自然 sticky/default sort，完整自然结果可访问 |
| 模型详情 | 与主列表采用同一隔离语义，不发生付费置顶 |
| zh/en/ru | 赞助、来源参考、纠错文案清楚且不改变含义 |
| 付费目标链接 | 同时有可见标签和 `sponsored noopener noreferrer` |

## Commands and browser evidence

1. 运行适用的精确测试命令，以及 `pnpm run typecheck` 与 `pnpm run build`；记录命令、退出码和任何预存失败。
2. 使用 `pnpm exec astro dev status` 取得实际本机地址（不要假定端口），通过浏览器从真实入口检查主列表、至少一次筛选/动态行为与一个模型详情页。
3. 保存简洁 QA 报告到 `docs/qa/p1_grok_t09122137.p005.md`，只含必要截图/路径、断言、结果和剩余风险；不提交 raw 响应、凭据或第三方完整内容。

## Done criteria

只有自动化与浏览器证据均通过、未引入排除范围能力、且 p003/p004 结果在真实入口可见，才可标记完成。若发现当前生产端口/部署与本机不同，仅报告为后续部署决策，不自行发布。
