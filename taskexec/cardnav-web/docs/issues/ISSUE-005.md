## 结论与发现

| 级别 | 基准位置 | 问题与影响 | 本次处理 |
|---|---|---|---|
| P1 | PRODUCT_STRATEGY §3 / ROADMAP §4 | “选官方”被一起排除，与有效外跳定义冲突，会激励偏向商业目标 | 官方合格外跳同样计入；未外跳决策单列帮助指标；位置和主体分别分类，总量跨类去重 |
| P1 | ROADMAP §2–3 / §6 | M0 整体基线、M1 总分与 M3 效果混作前置，低流量或方法未定时可能卡住全链路 | 依赖明确到最小计量、核心信任、流程可用；基线/增长另行观察，总分保留为条件性增强，不假标整个里程碑 done |
| P1 | PRODUCT_STRATEGY §5 / ROADMAP M5a | 只有商业产品清单，缺审核、到期/停投、异常目标、库存冲突及交付结算要求 | 补齐最小投放生命周期与验收；先受控记录/既有配置，不建设广告平台 |
| P2 | PRODUCT_STRATEGY §3 / ROADMAP M2–M4 | 用户场景宽泛，工具像默认交付，缺少替代方案、单一切入点与可停止实验 | 首轮一个用户任务/页面族，先复用已有路径；实验卡复用 tasklist Detail，限制范围和投入，不新增队列系统 |
| P2 | PRODUCT_STRATEGY §6 / ROADMAP §4 | 质量护栏分散，缺失败时用户看到什么、谁验收的统一映射 | 四类失败路径绑定 M0/M1/M3/M5/M8，覆盖缺失、空值、冲突、过期、丢事件、停投与部分更新 |
| P2 | PRODUCT_STRATEGY §7 / ROADMAP M5a | “恰当标记”不够可验收，视觉广告标签易替代技术链接属性 | 写明付费链接 sponsored 与视觉标签分别验收；引用 Google 官方说明，不推导法律合规保证 |

这些是设计缺口/依赖风险，不是宣称已经发生的生产故障。修订没有改广告/固定赞助优先、其后我方站点、自然评分独立或两项创新的已确认方向。

## Dream state delta / 依赖图

现有目录与数据基础 -> 一个可测、可信的比较场景 + 可交付固定赞助 -> 经需求/续约证明后扩展到持续更新的决策与商家增长业务。长期愿景保留，但不是十二个月交付承诺。

主依赖图已经加入 ROADMAP §2；原两份主文档没有 ASCII 图需要删除。这里展示投放状态验收模型，不是新增服务设计：

```text
候选/待审核 -> 审核通过且处于约定期间 -> 展示 -> 到期/暂停 -> 不展示
                    |                       |
                 审核不通过              确认目标异常
                    +----------------------> 不展示
暂停后恢复 -> 重新核准期间/素材/目标 -> 才允许再次展示
```

## Error / Rescue 与 Failure modes

本轮没有新方法、端点、异常类或部署，所以不虚构 exception class。下表是未来实现必须覆盖的产品失败合同；代码处理/日志/测试均需在相应实施任务验证，不能标为已经通过。

| 路径 | 异常/边界 | 用户或运营处理 | 验收/观测 |
|---|---|---|---|
| 比较/推荐 | 缺输入、空目录、不可比单位、过期/冲突证据 | 补输入/空态/未知/过期提示，不补造推荐 | M1/M3/M8 的单元、数据整合和真实入口用例；记录来源/版本 |
| 外跳/统计 | 重复、离页丢事件、禁用追踪、无回传 | 不阻断外跳；排重、缺失单列，不补造人数/成交 | M0/M5 重复与失败事件验收，记录覆盖率；不以敏感身份追踪补漏 |
| 商业位 | 未审核、到期、暂停、异常目标、库存冲突、旧缓存 | 停止受影响曝光；重新加载/发布后仍停投，恢复需审核 | M1/M5 边界/并发冲突/旧缓存用例；保留投放与处理记录 |
| 数据/发布 | 来源错误、部分更新、错误发布 | 保留历史，提示异常，不冒充全量最新；停止扩展、走既有回退 | M8 失败注入、审计、恢复演练；独立授权采集/部署 |
