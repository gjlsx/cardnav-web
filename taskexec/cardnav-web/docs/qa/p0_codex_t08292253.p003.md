## 修改

新程序增加独立 MySQL 门面和默认关闭的 merge/import worker：

- `scripts/crawlee_collection/database.py` 在活动窗口内复用一个连接，`connection_idle_ttl_s` 默认 600；空闲到期、closed 或 ping 失败才关闭并重建。
- `run_in_transaction` 在同一连接上 commit，异常先 rollback。
- worker 不自动启动；`run_once` 串行处理 `raw_completed` batch，进程内同一时刻只能 `start` 一个实例。
- 门面调用既有 `CollectionRepository` / `RuntimeImporter`，不新建业务 schema，也不调用 legacy `collect.py` 采集入口。
